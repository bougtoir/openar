# 電子麻酔記録システム (Electronic Anesthesia Record System)

VitalDBと連携したオフライン対応の電子麻酔記録デスクトップアプリケーション

## 機能概要

### 3パネル構成
- **パネル1** (0-20% X, 0-100% Y): 設定・入力パネル
  - リマークス入力
  - 薬剤投与記録
  - 輸液管理
  - 表示設定
  - VitalDBパラメータ選択

- **パネル2** (20-100% X, 40-100% Y): 記録表示パネル
  - 薬剤投与記録 (60%)
  - 輸液記録 (30%)
  - イベント記録 (10%)

- **パネル3** (20-100% X, 0-40% Y): バイタルサイン表示
  - リアルタイムチャート表示
  - 複数パラメータ同時表示

### 主要機能
- オフライン動作対応
- VitalDB API連携 (シリアルデバイス対応)
- 外部設定ファイル対応
- 持続投与薬剤の視覚的表示
- 時間指定可能な記録入力
- カスタマイズ可能な表示設定

## インストール・実行方法

### 必要環境
- Node.js (v16以上)
- npm または yarn

### セットアップ
```bash
# 依存関係のインストール
npm install

# 開発モードで実行
npm run dev

# 本番モードで実行
npm start

# アプリケーションのビルド
npm run build
```

### 配布用パッケージ作成
```bash
npm run dist
```

## 設定ファイル

### config/drugs.csv
薬剤設定ファイル
```csv
name,unit,continuous,color
酸素,L/min,false,#0066CC
セボフレン,%,true,#FF6600
```

### config/remarks.csv
リマークス設定ファイル
```csv
name,icon
麻酔開始,×
麻酔終了,×
```

### config/ivfluids.csv
輸液設定ファイル
```csv
name,initialVolume
生理食塩水,500
リンゲル液,500
```

### config/vitalsigns.csv
バイタルサイン設定ファイル
```csv
name,symbol,color,range
心拍数,♥,#FF0000,40-150
酸素飽和度,○,#0066FF,80-100
```

## デフォルト設定

### 薬剤
- 酸素 (L/min)
- セボフレン (%)
- ミダゾラム (mg)
- デクスメデトミジン (mg/kg/hr)
- ロピバカイン (ml/hr)
- 等比重マーカイン (ml)

### バイタルサイン
- 心拍数
- 酸素飽和度
- 血圧 (収縮期・拡張期)
- 体温
- 呼気二酸化炭素
- 呼気麻酔ガス濃度

## 使用方法

### リマークス入力
1. プルダウンから定型リマークスを選択、または自由記載
2. 時刻指定可能 (デフォルトは現在時刻)
3. ワンクリックボタン: 麻酔開始/終了、手術開始/終了

### 薬剤投与記録
1. 薬剤選択
2. 投与量入力
3. 時刻指定 (オプション)
4. 持続投与は自動的にダッシュ表示

### 輸液管理
1. 輸液種類選択
2. 開始時残量・流量入力
3. 持続投与として記録

### 表示設定
- 時間枠: 4/8/16時間
- 薬剤表示数: 10/20アイテム

## VitalDB連携

本アプリケーションはVitalDB APIと連携し、医療機器からのシリアル通信によるバイタルサイン取得に対応しています。オフライン環境での使用を前提として設計されています。

## 技術仕様

- **フレームワーク**: Electron
- **チャート**: Chart.js
- **シリアル通信**: SerialPort
- **設定管理**: CSV形式
- **レイアウト**: CSS Grid
